# Строки, векторы и словари. Вариант 13

Программа обрабатывает текстовую строку: из исходной фразы формируется новая строка, содержащая только буквенные символы (пробелы, цифры и знаки препинания удаляются).

## Задание

1. Считать одну строку (фразу).
2. Проверить корректность ввода:
   - чтение прошло успешно;
   - длина строки от 1 до 200 символов.
3. Сформировать результат: в новую строку попадают только символы, для которых `isalpha` истинно (буквы), в исходном порядке.
4. Вывести результат.

При некорректном вводе программа выводит:

```text
INVALID
```

и завершается с кодом 1.

Если в строке не оказалось ни одной буквы, результат преобразования пустой; по условию задания пустой результат обозначается:

```text
EMPTY
```

## Формат ввода

Одна строка — исходная фраза. Строка может содержать пробелы (в том числе в начале и конце), цифры и знаки препинания. Кавычки в примерах задания обозначают только границы строки и **не вводятся**.

В примере задания строка показана так:

```text
" Cat a12 dog Cat "
```

фактически вводится:

```text
 Cat a12 dog Cat 
```

## Формат вывода

Одна строка — результат преобразования (только буквы исходной строки в том же порядке).

## Пример работы

Ввод:

```text
 Cat a12 dog Cat 
```

Вывод:

```text
CatadogCat
```

## Особые случаи

| Ввод | Вывод |
|---|---|
| ` Cat a12 dog Cat ` | `CatadogCat` |
| `a` | `a` (минимальный ввод) |
| ` 12 34 ` | `EMPTY` (нет подходящих элементов) |
| пустая строка | `INVALID` (длина меньше 1) |
| строка длиннее 200 символов | `INVALID` |
| ошибка чтения / EOF | `INVALID` |

## Запуск

### Компиляция в консоли (g++)

```bash
g++ srt_vec_dic.cpp -o srt_vec_dic
./srt_vec_dic
```

Для Windows:

```bash
srt_vec_dic.exe
```

### Visual Studio

1. Открыть проект, файл `srt_vec_dic.cpp` должен быть добавлен в **Source Files**.
2. Собрать решение: `Ctrl+Shift+B` (или `F7`).
3. Запустить: `Ctrl+F5`.

Ввод подаётся с клавиатуры либо через перенаправление стандартного потока ввода из файла.

## Ограничения

- Максимальная длина строки: 200 символов (`maxSize = 200`).
- Минимальная длина строки: 1 символ.
- В результат попадают только символы, распознаваемые `isalpha` (в стандартной локали — буквы латиницы).
- Результат сохраняет исходный порядок символов.

## Проверка

Ожидаемые результаты сначала вычисляются вручную, затем сравниваются с выводом программы:

1. ` Cat a12 dog Cat ` → `CatadogCat`
2. `a` → `a`
3. ` 1 2 3 ` → `EMPTY`
4. `` (пустая строка) → `INVALID`
5. строка из 201 символа → `INVALID`
